# Трассировка — Value Sets

## 1. Назначение документа

Документ показывает, какие факты перенесены в пакет Value Sets, чем они
подтверждены и какие вопросы остаются открытыми. Он не является вторым
архитектурным описанием.

## 2. Источники и требования

| Источник | Требование или тезис | Решение | Документ-владелец | Статус |
| --- | --- | --- | --- | --- |
| [`DMP.Platform.ValueSets`][values-project] | Сущности, сервисы, репозиторий, `DbContext`, `DI` и контроллеры | Подтверждённые факты перенесены в архитектуру, исполнение и эксплуатацию | Value Sets | Подтверждено MVP |
| [`DMP.Platform.Contracts.ValueSets`][contracts] | Запросы, ответы и перечисления | Контракты перенесены без описания внутренней реализации | Value Sets | Подтверждено MVP |
| [`Композиция host-приложения`][host-composition] | Адаптеры проекции и начальных данных, средство разрешения значений Runtime и инициализатор | Описана зависимость от композиции host-приложения | Value Sets / host-приложение | Подтверждено, но ограничено |
| [`Интерфейсы исполнения`][runtime-interfaces] | `IRuntimeValueSetResolver` и граница материализации | Зафиксирована граница использования, а не владение материализацией | Object Runtime / host-приложение | Подтверждено, но ограничено |
| Studio frontend Value Sets | Маршрут, навигация, feature provider, настроенные представления и локализованные подписи | Интеграция Studio перенесена в `06_user_experience.md`; общая оболочка остаётся у фронтенд-платформа | [исходники интеграции Studio][studio-provider], [маршрут][studio-route], [навигация][studio-navigation] | Подтверждено MVP |
| [`Integration tests`][api-tests] | API, bootstrap и свидетельство работы Runtime | Тесты указаны как свидетельство, результаты не заменяют запуск тестов | Value Sets | Подтверждено MVP |
| [Платформенный глоссарий][platform-terms] | Русские термины, английские названия и технические алиасы | Термины используются в пакете | Platform Core | Принято целевое решение |
| Исходные требования Value Sets | Редактор, иерархия и модель владения | Перенесены только части, подтверждённые кодом и контрактами | Value Sets | Подтверждено, но ограничено |

## 3. Принятые решения

| Тема | Принятое решение | Основание | Документ-владелец | Статус |
| --- | --- | --- | --- | --- |
| `ValueSetDataSet` и `ValueSetItem` | Канонические данные Value Sets хранятся в этих сущностях | Сущности, EF mapping и миграция | `02_architecture.md` | Подтверждено MVP |
| Области данных `Global`/`Tenant`/`Site` | Область хранится у строки, `Site` требует `Tenant` | Поля сущности и проверки сервиса | `02_architecture.md`, `04_runtime.md` | Подтверждено MVP |
| Приоритет `Site` > `Tenant` > `Global` | Более узкая область заменяет строку с тем же `Code` | Реализация чтения и редактора | `04_runtime.md` | Подтверждено MVP |
| Родительская связь и проверка циклов | `ParentItemId` допустим только для `Hierarchical`; циклы отклоняются | Проверки API и seed writer | `04_runtime.md` | Подтверждено MVP |
| Чтение через Runtime/API | Value Sets предоставляет read API и application-порт; материализация принадлежит потребителю | Контроллеры, контракты и resolver host-приложения | `03_contracts.md`, `04_runtime.md` | Подтверждено, но ограничено |
| Операции с данными без удаления | Создание, изменение, активация и деактивация есть; удаления нет | Публичный API и сервис | `03_contracts.md` | Подтверждено, но ограничено |
| Проекция и начальные данные baseline | Поставка зависит от host-адаптеров; платформенный модуль имеет NoOp по умолчанию | Host composition | `03_contracts.md`, `08_operations.md` | Подтверждено, но ограничено |
| Редактор данных в Studio | В Studio зарегистрированы feature provider, маршрут, навигация и настроенные представления Value Sets | Общая оболочка и базовые средства отображения принадлежат фронтенд-платформа | `06_user_experience.md` | Подтверждено MVP |

## 4. Расхождения и открытые решения

| Тема | Текущее подтверждённое состояние | Расхождение или неопределённость | Влияние на текущую документацию | Статус сведения | Владелец / следующий шаг | Документ для обновления после решения |
| --- | --- | --- | --- | --- | --- | --- |
| Историческое имя области данных из требований | В коде и API используются `SiteId` и `Site` | Историческое имя не используется в новой терминологии | Не блокирует текущую документацию | Не переносить: устарело или противоречит MVP | Value Sets / не возвращать термин | `00_platform_overview.md`, `01_scope.md` |
| `ValueSet.Fields[]` и дополнительные поля элементов | В проверенной модели таких полей нет | Требование не подтверждено текущим контрактом | Не блокирует текущую документацию | Будущая доработка | Value Sets / отдельное решение о модели | `02_architecture.md`, `03_contracts.md` |
| `SystemEnum` как редактируемый набор | Value Sets его не обслуживает | Источник значений принадлежит Configuration и системному поставщику | Не блокирует текущую документацию | Владелец другой области | Configuration / не переносить в Value Sets | `01_scope.md` |
| Локализация элементов отдельной моделью | Подтверждены `Title` и display resolver | Отдельная модель локализаций элементов не найдена | Не блокирует текущую документацию | Будущая доработка | Value Sets / определить модель при необходимости | `03_contracts.md`, `04_runtime.md` |
| Экспорт и импорт между окружениями, управление нормативными данными | Отдельный контракт Value Sets не подтверждён | Требуется отдельная возможность и владелец | Не блокирует текущую документацию | Будущая доработка | Value Sets / Configuration / определить владельца | `03_contracts.md`, `08_operations.md` |
| Интеграция редактора в Admin и другие приложения | Интеграция редактора в Studio подтверждена | Отдельная интеграция в другие приложения не найдена в проверенном источнике | Не блокирует текущую документацию Studio | Будущая доработка | фронтенд-платформа / владельцы приложений | `06_user_experience.md` |
| Терминология `Site` в Studio | В технических контрактах и документации используется `Site` / «Площадка» | В одном frontend-переводе обнаружена отдельная русская подпись; документация не использует её и сохраняет единую терминологию | Не меняет технический контракт, но требует согласования UI-термина | Расхождение кода и источника | фронтенд-платформа / проверить перевод | `06_user_experience.md`, glossary |

### 4.1. Открытые решения

| ID и тема | Текущее подтверждённое состояние | Расхождение или неопределённость | Влияние на текущую документацию | Статус сведения | Владелец / следующий шаг | Документ для обновления после решения |
| --- | --- | --- | --- | --- | --- | --- |
| `VS-DEC-01` — tombstone для скрытия унаследованного элемента | Прямое изменение унаследованной строки отклоняется | Не определён способ скрыть её без создания отдельной строки | Не блокирует текущий API и описание MVP | Открытый вопрос | Value Sets / выбрать модель удаления или tombstone | `02_architecture.md`, `03_contracts.md`, `04_runtime.md` |
| `VS-DEC-02` — семантика `Configurable` и `Overrideable` | Проверяются `Fixed` и разрешение переопределения Tenant | Полная матрица политик не подтверждена | Не блокирует перечисление текущих проверок | Открытый вопрос | Value Sets / Configuration / согласовать матрицу | `03_contracts.md`, `05_security_and_audit.md` |
| `VS-DEC-03` — сброс кэша | Контракт события Value Sets не найден | Не определён отдельный механизм уведомления потребителей | Не блокирует текущий API без заявленной гарантии кэша | Открытый вопрос | Value Sets / Runtime / определить контракт события | `04_runtime.md`, `03_contracts.md` |
| `VS-DEC-04` — конфликт начальных данных | Seed обновляет или создаёт строки через host-адаптер | Политика конфликта с пользовательскими изменениями не задана | Не блокирует описание текущего пути начальных данных | Открытый вопрос | Configuration / Value Sets / определить политику | `08_operations.md`, `03_contracts.md` |
| `VS-DEC-05` — интеграция редактора в Admin и другие приложения | Интеграция в Studio подтверждена | Для других приложений отдельный маршрут и набор представлений не подтверждены | Не блокирует текущий пакет Studio | Будущая доработка | фронтенд-платформа / владельцы приложений | `06_user_experience.md` |

| Редактор данных в Studio | `06_user_experience.md` | Обновить при изменении route, navigation, feature provider или представлений | Текущая интеграция перенесена и подтверждена |
| Будущие решения | `90_traceability.md` и backlog | После решения изменить документ-владелец и оставить устойчивую запись | Открыто или направлено владельцу |

Пакет Value Sets находится в целевой папке `06_value_sets/`. Переходная папка
`05_value_set_data/` не является нормативным пакетом и удалена после разбора.
`ValueSet` не перенесён из владельца Configuration: в Value Sets описана только
связь опубликованной схемы с данными. Будущие темы не представлены как текущие
гарантии.
