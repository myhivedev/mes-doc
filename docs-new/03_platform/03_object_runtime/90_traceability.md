## 1. Назначение документа

Документ связывает исходные материалы Object Runtime с новым комплектом `03_platform/03_object_runtime/`, фиксирует открытые решения и показывает, какие темы переданы другим владельцам. Он не является архивом старых документов и не заменяет документы `00`-`08`.

Переходная папка `03_platform/10_object_runtime/` удалена и больше не является
источником нормативного содержания. Активные ссылки в документации переведены
на канонические документы `03_platform/03_object_runtime/`. Исторические
упоминания старого пути в архивном обзоре и документационной автоматизации
сохраняются как отдельный маршрут задачи `PCDOC-OR-03` и не являются ссылками
на действующий пакет.

## 2. Открытые решения и будущие доработки

Строка со статусом сведения `Открытый вопрос` означает, что для конкретной
гарантии, границы или промышленной готовности требуется решение владельца.
Такой статус сам по себе не блокирует описание подтверждённого поведения MVP.
Строка со статусом `Будущая доработка` означает, что возможность отсутствует
или ограничена в MVP, а решение не требуется для этой версии документации.
Статус документа во frontmatter ведётся отдельно.
Колонка `Влияние на текущую документацию` отдельно показывает, блокирует ли
тема описание MVP, относится ли она к будущей доработке или должна быть
передана другому владельцу.

## 4. Темы, переданные другим владельцам

| Тема | Владелец | Почему не входит в Object Runtime |
| --- | --- | --- |
| `ArtifactDocument`, `ArtifactNode`, `ArtifactValue`, `EffectiveArtifactDocument` | Configuration | Каноническая модель артефакта и слияние effective-значений являются контрактами Configuration. |
| Свойства схем `ObjectType`, `View`, `Action` | Configuration | Runtime использует effective-метаданные, но не определяет свойства схем. |
| Компонент отображения, компоновка, элементы управления, общие пакеты | фронтенд-платформа | Object Runtime возвращает серверные контракты; интерфейс формируется в другом месте. |
| Команды, переходы и история Workflow | Workflow | Object Runtime только проецирует состояние и отправляет запрос инициализации. |
| Вычислители правил и их классификация | Rules | Runtime может вызывать gateway; смысл вычисления принадлежит Rules. |
| Хранение, срок хранения и поиск аудита | Audit History | Object Runtime передаёт сведения аудита через приёмник. |
| Хранение outbox, повторные попытки и доставка | Integration Events | Object Runtime публикует полезную нагрузку через абстракцию. |
| Счётчики нумерации и момент назначения | Numbering | Runtime учитывает метаданные; смысл счётчиков принадлежит Numbering. |
| Предметные инварианты сущностей | Domain Modules | Прикладные модули владеют бизнес-объектами и их хранилищами. |
| Схемы `Report` и `Output`, endpoint генерации результата и служебные параметры report/output | Reporting Output | Runtime-проект содержит реализацию endpoint и сервисов, но Object Runtime не владеет моделью отчёта или output. Endpoint подтверждён [controller][runtime-controller]. Целевой маршрут — пакет `03_platform/11_reporting_output/`; до его появления тема остаётся маршрутизированной здесь как владелец другой области. |

| Конвейер изменения объекта | Object mutation pipeline | `ObjectMutationPipeline` | Кандидат | Единый порядок проверок, транзакции, жизненного цикла, аудита и события завершения. Кандидат перенесён в [глоссарий Object Runtime](../../11_glossary/object_runtime_terms.md). |
| Набор данных объекта | Object Dataset | `ObjectRuntimeDatasetDescriptor` | Кандидат | Набор данных, связанный с описанием конкретного типа объекта для `List` и `Lookup`; не путать со Standalone Dataset. |

| Групповое действие | Bulk action | `RuntimeObjectBulkActionRequest` | Кандидат | Действие для явно выбранного списка идентификаторов; выбор по фильтру пока не входит в текущий контракт. |
| Создание на основании существующего | Create from existing | `RuntimeObjectCreateFromExistingRequest` | Кандидат | Подготовка несохранённой формы из существующего объекта с переносом разрешённых значений. Кандидат перенесён в [глоссарий Object Runtime](../../11_glossary/object_runtime_terms.md). |
