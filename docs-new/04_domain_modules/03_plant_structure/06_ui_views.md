# UI-представления - 03 Производственная структура

## 1. Назначение документа

Документ описывает пользовательские представления модуля `03 Plant Structure`: списки, списки выбора, карточки, вкладки, фильтры, сортировку и источники значений.

Доменная модель описана в `02_domain_model.md`. Runtime-ограничения выбора ссылок описаны в `03_object_runtime_model.md`. Правила проверки описаны в `05_rules.md`.

## 2. Общие решения UI

UI модуля строится поверх Object Runtime.

Стандартные команды карточек и списков используются по правилам платформы:

- создание;
- изменение;
- сохранение;
- отмена изменений;
- удаление или архивирование, если действие доступно объекту;
- обновление данных;
- управление колонками;
- строка поиска;
- фильтр строк;
- пагинация;
- переходы жизненного цикла для `ProductionUnit` и `Subcontractor`.

В UI модуля v1 не включаются:

| Элемент источника | Решение |
|---|---|
| Вкладка `Настройки предприятия` | Не входит в модуль; settings ведутся через Studio Settings и регистрируются модулями-владельцами. |
| Вкладка `Параметры операций` | Не входит в модуль. |
| Поля `Dept` | Не входят в доменную модель модуля. |

| МХ выпуска | `OutputWarehouse` | редактируется по правилам жизненного цикла владельца |
| Ячейка выпуска | `OutputWarehouseBin` | редактируется по правилам жизненного цикла владельца |
| МХ брака | `ScrapWarehouse` | редактируется по правилам жизненного цикла владельца при `IsSegmentLevel = true` |
| Ячейка брака | `ScrapWarehouseBin` | редактируется по правилам жизненного цикла владельца при `IsSegmentLevel = true` |
| Переместить годные | `TransferYieldDefaultType` | редактируется по правилам жизненного цикла владельца при `IsSegmentLevel = true` |
| Переместить отклоненные | `TransferRejectDefaultType` | редактируется по правилам жизненного цикла владельца при `IsSegmentLevel = true` |
| Переместить брак | `TransferScrapDefaultType` | редактируется по правилам жизненного цикла владельца при `IsSegmentLevel = true` |

Для каждой пары `*Warehouse` / `*WarehouseBin` поле выбора ячейки недоступно, пока не выбрано соответствующее место хранения. Lookup ячейки фильтруется по выбранному месту хранения. При очистке или замене места хранения UI очищает выбранную ячейку; после замены ячейка выбирается заново.

Кроме зависимости `*WarehouseBin` от соответствующего `*Warehouse`, ограничения `IsSegmentLevel` и правил жизненного цикла владельца, UI v1 не устанавливает динамических зависимостей между полями настроек. Изменение `Transfer*DefaultType` не делает другие поля обязательными, не блокирует и не очищает их. Пользователь отвечает за содержательную корректность выбранного сочетания значений до уточнения логики на последующих этапах.

Для владельца в состоянии `Draft` доступность полей дополнительно определяется правами пользователя и условиями `IsSegmentLevel`. Для владельца в состоянии `Published` или `Archived` вся вкладка отображается только для чтения. UI не предоставляет роли `PlantStructureStorageResponsible` возможность самостоятельно выполнить `ReturnToDraft`.

Поля `InventoryStatus` и `Transfer*DefaultStatus` в UI v1 не выводятся. Их nullable GUID-колонки зарезервированы в физической модели и будут добавлены в форму после появления runtime-контракта и lookup `InventoryStatus` в модуле производственной логистики.

## 8. Списки выбора

| Список выбора | Источник данных | Используется для |
|---|---|---|
| Производственная единица | `ProductionUnit.Lookup` | `ProductionUnit.Parent`, `ProductionUnit.Main` в режиме чтения/служебного выбора |
| Организационная единица | `OrganizationalUnit.Lookup` | Места хранения и внешние ссылки смежных модулей |
| Место хранения | `OrganizationalUnit.Lookup` с фильтром активных записей по `IsInventoryStorageLocation = true`, без фильтра по состоянию Workflow | `StorageArea.Warehouse`, `WarehouseBin.Warehouse`, поля `*Warehouse` |
| Организация | `Company.Lookup` | `ProductionUnit.Company` |
| Контрагент | `Contractor.Lookup` из `01_general_master_data` | `Company.Contractor`, `Subcontractor.Contractor` |
| Зона хранения | `StorageArea.Lookup` | `WarehouseBin.StorageArea` |
| Тип складской ячейки | `WarehouseBinType.Lookup` | `WarehouseBin.WarehouseBinType` |
| Складская ячейка | `WarehouseBin.Lookup` | `WarehouseBin.Parent`, поля `*WarehouseBin` |

Контекстные ограничения списков выбора описаны в `03_object_runtime_model.md` и проверяются правилами `05_rules.md`.
