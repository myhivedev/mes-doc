# Пользовательские представления - 06 Управление проектами

## 1. Назначение документа

Документ определяет списки, карточки, вкладки, окна выбора, колонки, поиск, фильтры и действия интерфейса PR06.

## 2. Общие правила интерфейса модуля

- основные пункты меню - `Проекты` и `Коды затрат`;
- архивные записи по умолчанию не показываются;
- архивный объект показывается при открытии сохраненной ссылки и в режиме просмотра архивных записей;
- недоступные действия скрываются в интерфейсе, но сервер повторно проверяет права и правила;
- этапы проекта показываются в иерархическом списке внутри карточки проекта;
- отдельный пункт меню `Этапы проектов` в MVP отсутствует;
- ошибки согласованности проекта и этапа показываются рядом с соответствующим полем;
- общие фильтры располагаются в раскрываемой панели `Фильтры`;
- системные поля администрирования не входят в предметные представления PR06.

Колонки:

| Наименование | `Project.Name` | по умолчанию |

| Изменено | `Project.ModifiedAtUtc` | по умолчанию |

Поиск:

| Параметр | Поля поиска | Оператор | Минимальная длина |

| Общий поиск | код или наименование проекта | содержит, без учета регистра | не задана |

Сортировка и группировка:

| Вид | Значение |
|---|---|
| Сортировка | по коду по возрастанию по умолчанию; пользовательская сортировка сохраняется |
| Группировка | нет |

Фильтры:

| Фильтр | Поле / параметр | Размещение | Оператор | Источник значений | Значение по умолчанию | Примечание |
|---|---|---|---|---|---|---|
| Архивность | `IsArchived` | панель фильтров | равно | системный признак | неархивные | режим «Все» не входит в пользовательское представление PR06 |
| Ответственное подразделение | `ResponsibleProductionUnit` | панель фильтров | равно | `ProductionUnit` | все | текущее предприятие |
| Ответственный | `ResponsiblePerson` | панель фильтров | равно | `Personnel` | все | доступные сотрудники |
| Исполнитель | `ExecutorOrganizationalUnit` | панель фильтров | равно | `OrganizationalUnit` | все | `ProductionUnit` и `Subcontractor` |

Предустановленные режимы:

| Режим | Условия | По умолчанию | Назначение |
|---|---|---:|---|
| Действующие проекты | `IsArchived = false` | да | Рабочий список проектов. |
| Все проекты | архивные и неархивные | нет | Поиск исторических и архивных проектов. |

Действия: `Создать`, `Открыть`, `Архивировать`, `Восстановить`, `Удалить` - в соответствии с правами и проверками [05_rules.md](05_rules.md).

### 4.2. Этап проекта. Карточка

| Параметр | Значение |
|---|---|
| Титул | Этап проекта |
| Вид представления | Карточка |
| Код представления | `ProjectPhase_DetailView` |
| Тип представления | `ObjectForm` |
| Объект данных | Этап проекта / `ProjectPhase` |
| Режимы карточки | Создание, изменение, просмотр |

Вкладки и группы полей:

| Вкладка | Содержимое |
|---|---|
| Основное | Проект, код, наименование, родительский этап, описание, ответственное подразделение, ответственный, исполнитель. |
| Дочерние этапы | Навигационный список непосредственных дочерних этапов. |
| Связанные документы | Существующие документы, связанные через PR05. |
| Администрирование | Технические поля Common только для просмотра. |

Правила формы:

- `Project` обязателен;
- при выборе этапа в контексте пустого проекта поле `Project` заполняется автоматически;
- после выбора проекта lookup `Parent` ограничивается этапами этого проекта;
- при смене проекта несовместимое значение `Parent` очищается или операция блокируется до исправления;
- поля ответственности не наследуются автоматически от проекта;
- даты, план-факт, baseline, контрольные точки и workflow в карточке отсутствуют.

Действия: `Сохранить`, `Создать подэтап`, `Архивировать`, `Восстановить`, `Удалить`, `Закрыть`.

## 6. Пустые состояния и ошибки

| Ситуация | Отображение |
|---|---|
| У проекта нет этапов | «Этапы проекта отсутствуют» и действие `Создать этап`, если есть право создания. |
| Для выбранного проекта нет доступных этапов | «Для проекта нет доступных этапов». |
| Архивный объект открыт по сохраненной ссылке | Объект доступен для просмотра; создание новой ссылки на него запрещено. |
| Родительский этап относится к другому проекту | Сохранение блокируется с указанием необходимости выбрать этап того же проекта. |
| Родительский код затрат относится к другому tenant | Сохранение блокируется с указанием необходимости выбрать код того же tenant. |
| У кода затрат есть дочерние элементы | Архивирование или удаление блокируется до обработки дочерних кодов. |
| Для tenant нет кодов затрат | «Коды затрат отсутствуют» и действие `Создать`, если есть право создания. |
| Нет права на действие | Команда скрывается или недоступна; сервер возвращает стандартную ошибку доступа. |
