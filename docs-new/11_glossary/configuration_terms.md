# Термины Configuration Platform DMP

## 1. Назначение документа

Документ фиксирует рабочие русские термины, preferred English и технические алиасы для платформенной области Configuration.

Русские термины берутся из backend security manifest, contracts и кода Configuration, если они совпадают с архитектурным смыслом. UI-подпись или имя класса не становятся архитектурным термином автоматически: если техническое имя уже закреплено в коде, оно указывается как алиас рядом с русским термином.

## 4. Термины, требующие владельца

| Формулировка | Почему требует уточнения | Предпочтительная форма |
| --- | --- | --- |
| Область действия (`Scope`) | Термин перегружен между security, configuration, settings и data. | Область конфигурации (`ConfigurationScope`) или область действия конкретного механизма. |
| Эффективное значение (`Effective`) | Может относиться к правам, настройкам или конфигурации. | Эффективная конфигурация, эффективные права или effective value настроек. |
| Базовая конфигурация (`Baseline`) | Может означать начальную поставку, system baseline level или snapshot. | Системная базовая конфигурация, базовый пакет конфигурации или baseline snapshot. |
| Артефакт (`Artifact`) | В Configuration означает конфигурационный артефакт; в других областях может быть документом или build artifact. | Конфигурационный артефакт. |
| Каталог (`Catalog`) | Может означать каталог безопасности, каталог конфигурации или каталог типов артефактов. | Каталог конфигурации, каталог безопасности или каталог типов артефактов. |
| Редактор (`Editor`) | Может означать экран фронтенда или server contract. | Редактор артефакта для server contract; экран редактора для фронтенда. |

## 5. Нежелательные формулировки

| Формулировка | Почему не использовать | Чем заменить |
| --- | --- | --- |
| Настройки | Смешивает Configuration с Settings и user preferences. | Конфигурация, настройка отображения, runtime setting или user preference по контексту. |
| Действующая конфигурация | Не закреплена в коде; может спорить с `Effective configuration`. | Эффективная конфигурация (`Effective configuration`). |
| Область действия без владельца (`Scope`) | Непонятно, речь о security, configuration, settings или data. | Область конфигурации, область действия роли, область настройки. |
| Целевой код (`TargetCode`) | Историческое имя в старых материалах; в новых публичных контрактах нужен стабильный code/origin. | `Code` или `OriginKey` по смыслу. |
| Источник без уточнения (`Source`) | Неясно, речь об исходном материале, источнике истины или источнике значения. | Исходный материал, источник истины или источник значений артефакта. |
| Редактор интерфейса для серверного контракта (`UI editor`) | Смешивает frontend-экран и backend contract. | Редактор артефакта для server contract, экран редактора для frontend. |
