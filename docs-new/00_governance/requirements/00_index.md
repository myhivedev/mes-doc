# Исходные требования

## 1. Назначение раздела

Раздел хранит входные требования, ограничения и утвержденные термины, от которых строится проектная документация DMP.

## 2. Документы

| Документ | Назначение |
|---|---|
| `001_dmp_functional_requirements_and_constraints.md` | Исходные функциональные требования, ограничения и термины `TERM-*`. |
| `../../11_glossary/platform_terms.md` | Общие платформенные термины. |
| `../../11_glossary/manufacturing_terms.md` | Производственные и прикладные термины, используемые в проектной документации модулей. |

## 3. Правило по терминам

Проектная документация использует раздел терминологии `../../11_glossary/`.

Исходные требования остаются источником утвержденных терминов `TERM-*`. Тематические глоссарии не переопределяют утвержденные термины, а фиксируют технические алиасы, область использования и термины-кандидаты.
