# Обзор модуля - 03 Производственная структура

## 1. Назначение модуля

Модуль `03 Plant Structure` предназначен для ведения производственной структуры предприятия: производственных единиц, субподрядчиков, балансовых организаций, мест хранения, зон хранения и складских ячеек.

Модуль является справочным. Он предоставляет устойчивые ссылки для производственных, ресурсных, логистических и аналитических сценариев, но не реализует управление ресурсами, движение запасов, расчет остатков, выполнение операций и настройки платформенного уровня.

## 2. Термины и имена классов

Термины модуля используются по исходным требованиям и тематическому глоссарию `../../11_glossary/manufacturing_terms.md`.

В проектных документах техническое имя класса указывается на английском языке, а русское название объекта - рядом с ним. В `02_domain_model.md` для этого используется отдельная колонка.

## 3. Основные объекты

| Объект | Русское название | Назначение |
|---|---|---|
| `OrganizationalUnit` | Организационная единица | Абстрактная ссылочная точка для собственных и внешних элементов производственной структуры. |
| `ProductionUnit` | Производственная единица | Собственный элемент производственной структуры: предприятие, площадка, подразделение, цех, участок, склад и другие типы. |
| `Subcontractor` | Субподрядчик | Внешний элемент производственной структуры. |
| `Company` | Организация | Балансовая организация. |
| `OrganizationalUnitInventoryParameters` | Параметры места хранения | Зависимые параметры места хранения. |
| `StorageArea` | Зона хранения | Зона внутри места хранения. |
| `WarehouseBinType` | Тип складской ячейки | Классификатор типов складских ячеек. |
| `WarehouseBin` | Складская ячейка | Ячейка внутри места хранения. |

## 4. Ключевые решения

- `OrganizationalUnit` является абстрактным объектом для ссылок; конкретные типы - `ProductionUnit` и `Subcontractor`.
- `ProductionUnit` и `Subcontractor` используют одну физическую таблицу `OrganizationalUnit` с дискриминатором `UnitKind`.
- В одном `Tenant` допускается несколько корневых `ProductionUnit` типа `Enterprise`.
- `Company` принадлежит модулю как балансовая организация.
- `Contractor` принадлежит `01 General Master Data`; ссылки из `Company` и `Subcontractor` необязательные.
- SystemEnum, используемые полями объектов модуля, принадлежат модулю; собственные `ValueSet` в модуле не вводятся.
- `Site / Площадка` является типом производственной единицы; платформенный `Site` не является объектом модуля.
- `PlantParameters` не является объектом модуля; настройки регистрируются владельцами прикладной логики.
- `ProductionUnitOperationParameters` принадлежит модулю управления ресурсами. Модуль 03 не владеет этой настройкой и не создает ее, но предоставляет `ProductionUnit` как внешний объект для ссылки.

## 5. Границы с соседними модулями

| Область | Решение |
|---|---|
| `00 Common` | Базовые типы, архивирование, мягкое удаление, аудит и общие правила Object Runtime используются без дублирования. |
| `01 General Master Data` | Владеет `Contractor` и классификаторами контрагентов. |
| Модуль управления ресурсами | Владеет ресурсами, рабочими местами, персоналом, оборудованием, графиками и назначениями. |
| Модуль производственной логистики | Владеет логистическими алгоритмами, движением запасов и статусами запасов. |
| Настройки ресурсов для операций | Модуль управления ресурсами владеет `ProductionUnitOperationParameters` и назначениями графиков для `ProductionUnit` и `Subcontractor`; модуль 03 предоставляет организационные единицы как внешние объекты и навигацию к связанным назначениям. |
| Платформа | Владеет `Tenant`, `Site`, settings, правами, Object Runtime и baseline-механизмами. |
