# Пользовательские представления - 01 General Master Data

## 1. Назначение документа

Документ фиксирует списки, карточки, вкладки и основные действия интерфейса модуля `01 General Master Data`.

Источник дополнительной информации по составу форм - ПР01, раздел `Описание форм и действий`.

Документ не повторяет полный состав полей. Поля описаны в `02_domain_model.md`, правила проверки - в `05_rules.md`, доступность типов объектов через Object Runtime - в `03_object_runtime_model.md`.

## 2. Общие правила интерфейса

Интерфейс GMD строится поверх Object Runtime.

- списковые формы показывают только неархивные и неудаленные записи по умолчанию;
- архивные записи показываются через общий фильтр Common `Показать архивные`;
- удаленные записи не показываются в обычных пользовательских списках;
- `TenantId` не показывается и не редактируется в рабочих формах;
- `Presentation` не редактируется как поле, а вычисляется Object Runtime;
- `Status` из ПР01 не показывается как универсальное физическое поле GMD;
- поля аудита, архива и удаления показываются через системную секцию `Администрирование`;
- `ExternalId` показывается только в административной секции или интеграционных представлениях;

ПР01 часто указывает `Status`, `Presentation`, `Created`, `Updated`, `IntegrationId` в таблицах форм. В целевой модели GMD эти элементы отображаются по правилам Common/Object Runtime и не дублируются в рабочих вкладках.

В таблицах этого документа ссылки вида `Object.Presentation` означают отображаемое значение ссылочного объекта, вычисленное Object Runtime. Это не физическое поле `Presentation` в таблице объекта.

### Группа единиц измерения. Форма строки пересчета

| Параметр | Значение |
|---|---|
| Титул | Пересчет единицы измерения |
| Вид представления | Форма строки |
| Код представления | `UnitOfOperation_DetailView` |
| Тип представления | `ObjectForm` |
| Объект данных | Единица операции / `UnitOfOperation` |
| Владелец | Группа единиц измерения / `UnitGroup` |
| Режимы карточки владельца | Изменение, просмотр |

Используется при создании или изменении строки `UnitGroup.UnitsOfOperation`.

Поля:

| Поле | Источник |
|---|---|
| В ЕИ | `ToUnit` |
| Коэффициент пересчета | `ConversionFactor` |
| Делимость | `IsDivisible` |
| Точность | `Precision` |
| Область применения | `ApplicationArea` |
| По умолчанию | `IsDefault` |

`ApplicationArea` вводится группой флажков по `UnitApplicationAreaFlags`: производство, закупки, сбыт. Если флажки не выбраны, строка применяется во всех областях.

При создании строки владелец заполняется автоматически:

```text
UnitOfOperation.UnitGroup = текущая UnitGroup
```

| Логистика | Производственно-логистические политики и значения по умолчанию из `Nomenclature`. |
| Упаковки | `PackSet` и коллекция `IndividualPacks`. |
| Тара | Правила вместимости `TransportUnitType -> ToNomenclature`. |
| Реквизиты | Коллекция `ParameterValues` и эффективная схема реквизитов. |
| Машиночитаемые идентификаторы | Отображается только если подключена общая возможность машиночитаемой идентификации. |
| Администрирование | Системная секция Common. |

В режиме создания карточка НП показывает только поля самой НП. Вкладки коллекций, вкладка `Реквизиты`, вкладки `Исполнения НП`, `Серийные номера`, `Упаковки`, `Тара` и `Машиночитаемые идентификаторы` доступны после первого сохранения НП.

Вкладка `Реквизиты` показывает только фактически созданные строки `ParameterValues`. Команда создания добавляет пустую редактируемую строку; список выбора `Реквизит` содержит применимые общие и видовые реквизиты без значения у текущей НП, а также реквизиты с `AssignmentArea = Nomenclature`, еще не назначенные этой НП. Уже выбранные в сохраненных и несохраненных строках реквизиты исключаются из списка.

После выбора реквизита его тип, код, назначение и типизированное значение по умолчанию заполняются из варианта выбора. В строке отображается редактор, соответствующий типу реквизита. Для реквизита области `Nomenclature` прямое назначение создается неявно при сохранении коллекции и удаляется вместе со строкой значения; для общих и видовых реквизитов удаляется только значение.

Режимы карточки:

| Режим | Отличия |
|---|---|
| `Create` | Показываются рабочие поля самой НП. Вкладки коллекций и связанные списки недоступны до первого сохранения НП. |
| `Edit` | Доступны рабочие поля и вкладки коллекций по правам, жизненному циклу и правилам объекта. |
| `View` | Все поля доступны только для чтения. Секция `Администрирование` добавляется по правилам Common. |

Вкладки `Замены` и `Документация` из ПР01 не проектируются как собственные сценарии GMD v1. Их владельцы проектирования - модули, которые отвечают за замены и документы.

Вкладка `Пересчеты` доступна в режимах создания, изменения и просмотра. При создании упаковки
пересчеты добавляются в черновую агрегированную коллекцию и сохраняются атомарно вместе с упаковкой.

номенклатуры, не настроив пересчет, и в системе останется номенклатура с нарушенной цепочкой пересчета.
При создании индивидуальной упаковки из коллекции номенклатуры поле `Nomenclature` заполняется
контекстом родительской карточки и доступно только для чтения. На вкладке `Пересчеты` используется
списочное представление `Nomenclature_UnitsOfOperation_ListView`, предоставляющее редакторы строк;
карточка `UnitOfOperation_DetailView` используется как представление отдельной строки.

В целевой архитектуре GMD не владеет шаблонами и значениями машиночитаемых идентификаторов. Вкладка или действие машиночитаемой идентификации подключаются только через общую возможность Common/Platform.
