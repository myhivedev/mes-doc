# Производственные и прикладные термины DMP

## 1. Назначение документа

Документ является рабочим тематическим глоссарием для производственных и прикладных терминов, которые используются в проектной документации `docs-new`.

Документ не заменяет исходные требования:

```text
../00_governance/requirements/001_dmp_functional_requirements_and_constraints.md
```

Если термин уже имеет `TERM-*`, его утвержденное определение находится в исходных требованиях. В этом документе фиксируются только технический алиас и использование в проектной документации.

## 2. Правила ведения

- Основной язык термина - русский.
- Английское имя указывается только как технический алиас для кода, API, контрактов или платформенного блока.
- Термин с `TERM-*` не переопределяется в этом документе.
- Термин без `TERM-*` имеет статус `Кандидат`.
- Нежелательные формулировки фиксируются только там, где есть риск путаницы.

## 3. Термины из исходных требований, используемые в модулях

| Источник | Термин | Технический алиас | Использование |
|---|---|---|---|
| `TERM-002` | Предприятие | `Enterprise` | Корневой тип производственной единицы в Plant Structure. |
| `TERM-003` | Организационная единица | `OrganizationalUnit` | Абстрактный объект Plant Structure для ссылок на внутренние и внешние элементы производственной структуры. |
| `TERM-004` | Производственная структура | `PlantStructure` | Прикладной модуль и иерархия производственных единиц. |
| `TERM-005` | Производственная единица | `ProductionUnit` | Внутренний элемент производственной структуры. |
| `TERM-006` | Организация | `Company` | Балансовая организация в Plant Structure. |
| `TERM-007` | Субподрядчик | `Subcontractor` | Внешняя организационная единица Plant Structure. |
| `TERM-008` | Контрагент | `Contractor` | Объект GMD. |
| `TERM-009` | Складская ячейка | `WarehouseBin` | Объект Plant Structure. |
| `TERM-010` | Зона хранения | `StorageArea` | Объект Plant Structure. |
| `TERM-011` | Номенклатурная позиция, номенклатура, НП | `Nomenclature` | Объект GMD. |
| `TERM-012` | Исполнение номенклатурной позиции, исполнение НП | `NomenclatureVariant` | Объект GMD. |
| `TERM-034` | Серийный номер, СН | `SerialNumber` | Объект GMD. |
| `TERM-035` | Реквизит номенклатуры | `NomenclatureParameter` | Объект GMD и схема дополнительных реквизитов. |

## 4. Термины-кандидаты GMD

| Термин | Технический алиас | Статус | Использование |
|---|---|---|---|
| Единица измерения | `Unit` | Кандидат | Справочник единиц измерения. |
| Группа единиц измерения | `UnitGroup` | Кандидат | Группа пересчета с базовой единицей измерения. |
| Единица измерения операции | `UnitOfOperation` | Кандидат | Единица измерения, допустимая для операции, и правило пересчета для конкретного владельца. |
| Группа номенклатуры | `NomenclatureGroup` | Кандидат | Иерархическая группа номенклатуры. |
| Вид номенклатуры | `NomenclatureKind` | Кандидат | Вид НП, используемый для классификации и набора реквизитов. |
| Набор упаковок | `PackSet` | Кандидат | Набор допустимых упаковок для НП. |
| Упаковка | `Pack` | Кандидат | Справочный объект упаковки, который может участвовать в пересчете через `UnitOfOperation`. |
| Тип единицы транспортировки | `TransportUnitType` | Кандидат | Справочный тип единицы транспортировки. |
| Фактическая единица транспортировки | `TransportUnit` | Кандидат | Экземпляр единицы транспортировки с номером. Не входит в GMD v1. |
| Назначение реквизита номенклатуры | `NomenclatureParameterAssignment` | Кандидат | Связь реквизита с видом НП или конкретной НП. |
| Значение перечислимого реквизита номенклатуры | `NomenclatureParameterEnumValue` | Кандидат | Локальное допустимое значение перечислимого реквизита НП. |
| Значение реквизита номенклатуры | `NomenclatureParameterValue` | Кандидат | Строка коллекции значений реквизитов НП. Наследуется от `NomenclatureParameterValueBase`; owner-specific аналоги используются для исполнения НП, серийного номера и объектов других модулей. |
| Группа контрагентов | `ContractorGroup` | Кандидат | Группа контрагентов. |
| Включение контрагента в группу | `ContractorInContractorGroup` | Кандидат | Связь контрагента с группой контрагентов. |
| Контакт контрагента | `ContractorContact` | Кандидат | Контакт в коллекции `Contractor.Contacts`. |

## 5. Термины-кандидаты Plant Structure

| Термин | Технический алиас | Статус | Использование |
|---|---|---|---|
| Площадка | `Site` | Кандидат | Тип производственной единицы и платформенный scope внутри tenant. В модуле Plant Structure площадка моделируется как `ProductionUnit` типа `Site`; платформенный `Site` не является объектом модуля. |
| Место хранения | `InventoryStorageLocation` | Кандидат | Роль организационной единицы, для которой ведутся параметры хранения, зоны хранения и складские ячейки. |
| Параметры места хранения | `OrganizationalUnitInventoryParameters` | Кандидат | Зависимые параметры организационной единицы, используемой как место хранения. |
| Тип складской ячейки | `WarehouseBinType` | Кандидат | Справочник типов складских ячеек. |

## 6. Нежелательные формулировки

| Формулировка | Почему не использовать | Чем заменить |
|---|---|---|
| Справочная идентичность экземпляра номенклатуры | Нет такого термина в исходных требованиях; формулировка не объясняет бизнес-смысл. | Серийный номер. |
| Транспортная единица | В требованиях используется формулировка `единица транспортировки`. | Единица транспортировки. |
| Основные данные (`Master data`) | В нормативных документах основной язык русский. | Основные данные. |
| Термин `Plant` без уточнения | Исторический платформенный термин смешивается с предприятием и производственной единицей. | `Site / Площадка` для платформенного scope и `ProductionUnit` для предметной производственной единицы. |
