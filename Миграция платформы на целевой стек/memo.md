| -------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |

| **Baseline Package**                   | Базовый пакет конфигурации                       | Набор исходных/базовых конфигурационных артефактов, используемых при формировании эффективной конфигурации                           |
| **Bootstrap**                          | Запуск / инициализация приложения           | Начальная последовательность запуска приложения и пользовательской сессии перед отображением основного интерфейса                                           |
| **BrowserRouter**                      | Маршрутизатор браузера                      | React-механизм маршрутизации приложения на основе URL браузера                                                                                              |
| **Business Object**                    | Бизнес-объект                                    | Объект предметной области, определяемый платформой или будущим MES-модулем                                                           |
| **BusinessObjectContract**             | Контракт бизнес-объекта                          | Программный контракт, описывающий возможности и структуру объекта для Object Runtime                                                 |
| **Central Admin**                      | Центральное администрирование                    | Административная часть платформы для управления предприятиями, tenant, глобальными параметрами и другими корпоративными настройками  |
| **Central Ingestion**                  | Центральный приём данных                         | Компонент Central-контура, принимающий данные/события от Local-контуров                                                              |
| **Central Platform**                   | Центральная платформа                            | Центральный экземпляр Platform Foundation, управляющий корпоративными настройками и взаимодействующий с Local-контуром               |
| **Central → Local Synchronization**    | Синхронизация Central → Local                    | Доставка конфигурации, справочных данных, параметров и административных команд из Central в конкретный Local-контур                  |
| **Central–Local Integration**          | Интеграция Central–Local                         | Полный механизм взаимодействия центрального и локальных контуров                                                                     |
| **Configuration**                      | Конфигурация                                     | Настраиваемое поведение платформы, которое может изменяться без изменения Java-кода                                                  |
| **Configuration Artifact**             | Конфигурационный артефакт                   | Самостоятельная единица конфигурации платформы, например ObjectType, View, Action, Workflow, Rule, Menu                                                     |
| **Configuration Context**              | Контекст конфигурации                       | Информация о текущем контексте работы Studio с конфигурацией, включая область, версии и состояние                                                           |
| **Configuration Explorer**             | Обозреватель конфигурации                   | Интерфейс Studio для просмотра и выбора конфигурационных артефактов                                                                                         |
| **Configuration Explorer Response**    | Ответ обозревателя конфигурации             | API-модель, передающая Studio данные для отображения Configuration Explorer                                                                                 |
| **Configuration Package**              | Пакет конфигурации                               | Версионированный набор конфигурационных артефактов, передаваемый из Central в Local                                                  |
| **Configuration Publication**          | Публикация конфигурации                          | Процесс перевода подготовленной конфигурации из draft в опубликованную версию                                                        |
| **Configuration Scope**                | Область действия конфигурации                    | Уровень, на котором действует конфигурация: Global, Tenant, Site/Local и т. п.                                                       |
| **Configuration Version**              | Версия конфигурации                              | Версия набора конфигурационных артефактов, которую можно передать, активировать или откатить                                         |
| **Configuration-driven UI**            | Интерфейс, управляемый конфигурацией        | Подход, при котором структура и поведение части пользовательского интерфейса определяются конфигурацией, а не жёстко зашиваются в React-код                 |
| **Configuration-driven UI Contract**   | Контракт UI, управляемого конфигурацией     | Формализованный контракт между серверной конфигурацией и frontend, определяющий, какие элементы и поведение Runtime UI могут быть построены из конфигурации |
| **ConfigurationArtifactEditorResponse**| Ответ редактора конфигурационного артефакта | API-модель, содержащая состояние конфигурационного артефакта для его редактирования в Studio                                                                |
| **Configured Feature**                 | Настроенная функциональная возможность      | Функциональность, доступность и параметры которой определяются конфигурацией платформы                                                                      |
| **Configured List View**               | Настроенное представление списка            | Runtime-компонент, отображающий список объектов согласно разрешённой конфигурации представления                                                             |
| **Configured Object Form**             | Настроенная форма объекта                   | Форма просмотра/создания/редактирования объекта, структура которой определяется runtime-конфигурацией                                                       |
| **Configured Object List View**        | Настроенное представление списка объектов   | Конкретный тип runtime-представления для отображения набора объектов                                                                                        |
| **Configured Runtime View**            | Настроенное Runtime-представление           | Представление интерфейса, структура и возможности которого определяются опубликованной конфигурацией                                                        |
| **Configured View Host**               | Хост настроенного представления             | React-компонент, подключающий настроенную модель представления к дереву компонентов React                                                                   |
| **Configured Workspace View**          | Настроенное представление рабочего места    | Runtime-представление, предназначенное для формирования рабочего пространства пользователя                                                                  |
| **Content Storage**                    | Хранилище содержимого                            | Технический механизм хранения файлов и бинарного содержимого, связанный с объектами через ContentRef                                 |
| **ContentRef**                         | Ссылка на содержимое                             | Типизированная ссылка на хранимый файл/бинарный объект вместо непосредственного хранения файла в бизнес-объекте                      |
| **Context Provider**                   | Провайдер контекста                         | React-компонент, предоставляющий дочерним компонентам общий контекст, например Platform Context                                                             |
| **Correlation ID**                     | Идентификатор корреляции                         | Идентификатор, позволяющий связать несколько событий и операций, относящихся к одному сквозному процессу                             |
| **CRUD**                               | Создание, чтение, изменение, удаление            | Базовый набор операций Create, Read, Update, Delete над объектами                                                                    |
| **CRUD Engine**                        | Универсальный механизм CRUD                      | Общий механизм выполнения CRUD-операций для различных типов объектов без реализации одинакового кода в каждом MES-модуле             |
| **Data Editor API**                    | API редактора данных                             | API для просмотра и изменения элементов справочных данных/Value Sets                                                                 |
| **Data Provider**                      | Провайдер данных                            | Компонент, предоставляющий Runtime UI данные объектов или конфигурации                                                                                      |
| **Data Set / Value Set**               | Набор справочных данных                          | Управляемый набор значений, используемый платформой и MES-модулями                                                                   |
| **Deduplication**                      | Дедупликация                                     | Устранение повторной обработки одного и того же события                                                                              |
| **DLQ / Dead Letter Queue**            | Очередь сообщений, не обработанных после ошибок  | Место, куда помещаются сообщения, которые не удалось обработать после предусмотренного количества попыток                            |
| **Draft**                              | Черновик                                         | Нередактируемая для Runtime, но ещё не опубликованная версия конфигурации                                                            |
| **Editor Model**                       | Модель редактора                            | Специализированная frontend-модель, предназначенная для редактирования конфигурации в Studio                                                                |
| **Editor Session**                     | Сессия редактирования                       | Состояние текущего редактирования в Studio, включая исходное состояние, локальные изменения и revision token                                                |
| **Effective Configuration**            | Эффективная конфигурация                         | Итоговая конфигурация после объединения применимых уровней и переопределений; именно её использует Runtime                           |
| **Effective Configuration Snapshot**   | Снимок эффективной конфигурации                  | Зафиксированное состояние эффективной конфигурации для конкретного контура/области действия                                          |
| **Effective Set**                      | Итоговый набор значений                          | Набор ValueSet после разрешения значений с учётом приоритетов Global → Tenant → Site                                                 |
| **EffectiveArtifactDocument**          | Итоговый документ артефакта                 | Серверная эффективная модель конфигурационного артефакта после применения соответствующих конфигурационных уровней                                          |
| **Enterprise**                         | Предприятие                                      | Независимый производственный контур/организация, для которой существует Local-экземпляр платформы                                    |
| **Enterprise Contour**                 | Контур предприятия                               | Автономный Local-контур конкретного предприятия                                                                                      |
| **Event Bus**                          | Шина событий                                     | Механизм передачи событий между компонентами платформы; в целевой архитектуре используется Kafka                                     |
| **Event Envelope**                     | Конверт события                                  | Стандартная оболочка события с Event ID, типом, Tenant, временем, Correlation/Causation ID и другими метаданными                     |
| **Event ID**                           | Идентификатор события                            | Уникальный идентификатор конкретного события, используемый в том числе для дедупликации                                              |
| **Execution**                          | Исполнение / Runtime                             | Пользовательское приложение, через которое выполняются операции платформы и в дальнейшем функции MES                                 |
| **Execution API**                      | API исполнения                                   | Независимый API Runtime-приложения; не предоставляет административные и Studio-операции                                              |
| **Execution UI**                       | Пользовательский интерфейс исполнения            | React-приложение Runtime, предназначенное для конечного пользователя                                                                 |
| **Extension Point**                    | Точка расширения                            | Формально определённое место, куда можно подключить функциональность нового MES-модуля или другой платформенной функции без изменения базового механизма    |
| **Feature Flag**                       | Функциональный переключатель                     | Настройка, позволяющая включать или выключать определённую функциональность без изменения кода                                       |
| **Foundation**                         | Основа / фундамент платформы                     | Общие технические механизмы, используемые всеми платформенными компонентами                                                          |
| **Frontend Platform**                  | Фронтенд-платформа                          | Общий клиентский слой для Admin, Runtime и Studio, содержащий общие пакеты, оболочку, маршрутизацию, UI и runtime-механизмы                                 |
| **Frontend Workspace**                 | Рабочая область фронтенда                   | Общая структура проекта frontend, объединяющая три приложения и общие npm/pnpm-пакеты                                                                       |
| **Global Admin**                       | Глобальное администрирование                     | Административное приложение/режим для управления всей распределённой платформой и всеми предприятиями                                |
| **Guard**                              | Предусловие / защитное условие                   | Условие, которое должно выполняться для разрешения перехода Workflow или выполнения определённой операции                            |
| **Hook**                               | React-хук                                   | Механизм React для доступа компонента к состоянию, данным и поведению frontend-платформы                                                                    |
| **Host**                               | Хост компонента/представления               | Технический React-компонент, который подключает и размещает настроенное представление или другой функциональный блок                                        |
| **Identity Context**                   | Контекст идентичности пользователя               | Информация о текущем аутентифицированном пользователе, полученная от Identity Provider                                               |

| **Idempotency**                        | Идемпотентность                                  | Возможность повторно обработать одну и ту же команду/событие без повторного изменения конечного результата                           |
| **Inbox**                              | Входящий журнал сообщений                        | Хранилище полученных сообщений, используемое для контроля повторной обработки и реализации идемпотентности                           |
| **Integration API**                    | API интеграции                                   | Независимый API для взаимодействия платформы с внешними системами                                                                    |
| **Integration Endpoint**               | Интеграционная конечная точка                    | Описание внешней системы/адреса, с которым может взаимодействовать платформа                                                         |
