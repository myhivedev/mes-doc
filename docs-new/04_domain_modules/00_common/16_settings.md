# Настройки - 00 Common

## 1. Назначение

Документ фиксирует настройки, владельцем смысла которых является `00 Common`.

Common описывает назначение настройки и правила ее использования прикладными модулями. Хранение значений, переопределение по области действия и получение эффективного значения выполняет общий механизм Settings.

## 2. Общие правила

- настройки Common не являются полями `CommonObject`;
- настройки Common не заменяют доменные поля прикладных модулей;
- если настройка влияет только на ввод или отображение, это указывается явно;
- прикладной модуль, который использует настройку Common, ссылается на этот документ и описывает только свое предметное применение.

## 3. TimeAmountFormat

`TimeAmountFormat` задает формат пользовательского ввода и отображения количественного времени: нормативного, планового, фактического, машинного, трудового и других значений времени, которые являются количеством времени, а не моментом времени суток.

Источник настройки - ПР09, строка параметров логистики предприятия:

```text
Формат длительности / DurationFormat / Enum; DurationFormatType / Да / = Standard /
Формат отображения длительности (времени) по умолчанию (стандартный, промышленный)
```

При разложении старого `PlantParameters` принято решение, что исходная настройка `DurationFormat` не принадлежит ПР03 и регистрируется владельцем общего смысла, то есть `00 Common`.

| Свойство | Решение |
|---|---|
| Код настройки | `Common.TimeAmountFormat` |
| Legacy/source alias | `PlantParameters.DurationFormat` / `DurationFormat` из ПР09. |
| Тип значения | `TimeAmountFormatType` из `02_domain_model.md`. |
| Значение по умолчанию | `Standard`. |
| Назначение | Формат ввода и отображения количественного времени. |
| Владелец смысла | `00 Common` |
| Где хранится значение | Общий механизм Settings. |
| Область применения | Прикладные формы и представления, где пользователь вводит или видит количественное время. |
| Влияет на хранение данных | Нет. |
| Влияет на единицы измерения | Нет. |

`TimeAmountFormat` не является единицей измерения и не заменяет `DurationUnit`.

Если прикладное поле хранит время в секундах, оно продолжает храниться в секундах. `TimeAmountFormat` определяет только пользовательское представление и ввод.

Допустимые значения определены системным enum `TimeAmountFormatType`:

| Значение | Представление | Пример для 5400 секунд |
|---|---|---|
| `Standard` | `hh:mm:ss` | `01:30:00` |
| `Industrial` | нормо-часы с тремя десятичными знаками | `1,500` для `ru-RU`, `1.500` для `en-US` |

`Industrial` означает десятичное представление часов. Например, `1,500` / `1.500` - это 1 час 30 минут, а не 1 час 50 минут.

## 4. Зависимость от культуры

`Standard` фиксирует структуру `hh:mm:ss`. Разделитель часов, минут и секунд - `:`. Он не зависит от культуры пользователя.

Поскольку значение является длительностью, а не временем суток, количество
часов не ограничено диапазоном `00..23`. Фактическая маска —
`[h...]:mm:ss`; например, 178200 секунд отображаются как `49:30:00`.

`Industrial` фиксирует точность: три десятичных знака нормо-часов. Десятичный разделитель зависит от культуры пользователя:

| Культура | Пример для 5400 секунд |
|---|---|
| `ru-RU` | `1,500` |
| `en-US` | `1.500` |

Группировка разрядов для `Industrial` не используется.

При преобразовании `Industrial` значение округляется до трех десятичных знаков
часа по правилу `MidpointRounding.AwayFromZero`. При обратном преобразовании
нормо-часов в целые секунды применяется то же правило. Каноническое значение в
прикладном хранилище остается количеством секунд.

## 5. Отличие от исходного ПР09

В ПР09 исходное имя настройки - `DurationFormat`, тип - `DurationFormatType`, русское имя - "Формат длительности".

В целевой модели имя уточнено:

```text
Common.TimeAmountFormat
TimeAmountFormatType
```

Причина изменения: настройка применяется не только к длительности процесса, но и к нормативному, плановому и фактическому количественному времени. Название `TimeAmountFormat` точнее отделяет этот смысл от формата времени суток и от формата `DateTime`.

## 6. Использование в прикладных модулях

Модуль, который использует `Common.TimeAmountFormat`, должен явно указать:

- какие поля используют настройку;
- в какой единице эти поля хранятся;
- что происходит при сохранении значения после пользовательского ввода.

Пример для ПР02:

```text
RateForSetupTime, RateForProcessingTime, RateForAuxiliaryTime,
RateForMachineTime, RateForTeardownTime хранятся в секундах.
Ввод и отображение выполняются с учетом Common.TimeAmountFormat:
Standard = hh:mm:ss, Industrial = нормо-часы с тремя десятичными знаками.
При сохранении значение пересчитывается в секунды.
```
